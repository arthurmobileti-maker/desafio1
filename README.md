# desafio1
Desafio 1 — Minha Loja: Simulador de Compras Sua missão é criar uma loja fictícia utilizando HTML, CSS e JavaScript.  Você deverá escolher o nome da loja, os produtos, os preços e a identidade visual. Pode ser uma lanchonete, loja de roupas, acessórios, jogos ou outro tema de seu interesse.
